# Don Bosco Youth Centre (DBYC) Basin Bridge, Chennai - 600 012
Official Web Portal & Progressive Web App (PWA).

### ✨ Features Included:
- **Dual Emblems**: Left: St. John Bosco portrait, Right: DBYC Youth Centre Emblem across entire app.
- **Hard Copy Document Scanner**: Optical Form Scanner replaces combined print button, auto-filling 18 registration fields.
- **Strict 1-to-1 Authentication**: Passwords/PINs unlock only their own account. No cross-account access.
- **Secure OTP Dispatch**: Plaintext OTP is hidden from UI; dispatched to mobile via SMS/WhatsApp and registered Email via Google Apps Script.
- **Center-Wide Daily Attendance**: Filter by 6 age categories/groups, choose any date, 1-tap fast attendance desk, QR camera & Google Lens.
- **Zero Paid Dependencies**: 100% Google Drive storage backend.
